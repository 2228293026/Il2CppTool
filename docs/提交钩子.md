# 让提交前钩子生效（第 142 轮加）

这个仓库有一个**提交前门禁钩子**：`.githooks/pre-commit`。
它会跑快速门禁，门禁红就**拒绝这次提交**。

```sh
git config core.hooksPath .githooks
```

## 为什么需要它

过去三轮里三次把 `.ci/selftest-gates.ps1` 的 UTF-8 BOM 弄丢了
（重写文件时不保留 BOM），其中两次**门禁的输出里已经报红了**
（`含 5852 个非 ASCII 字符却没有 BOM`），我读过去了。

机制没起作用的原因是：`check-all.ps1` 要**人手动跑**，
而实际流程是「改完 → 直接 commit」。CI 会红，但那时已经推送了。

> 一条只有手动运行才存在的检查，在「人不可能每次都记得跑」的现实中，
> 约等于没有。

钩子把这个「记得」交给 git。

## 用法

| 场景 | 命令 |
|---|---|
| 默认（快速门禁，约 10 秒） | `git commit -m "..."` |
| 完整验证（含 clang-tidy 与 40 条自检，十几分钟） | `$env:IL2CPPTOOL_FULL_GATE=1; git commit -m "..."` |
| 明知会红且清楚原因 | `git commit --no-verify` —— **请在提交说明里写清为什么** |

Windows 上要手动设置环境变量时：

```powershell
$env:IL2CPPTOOL_FULL_GATE='1'
git commit -m "..."
Remove-Item Env:\IL2CPPTOOL_FULL_GATE
```

## 两点提醒

- **`core.hooksPath` 是本地设置，不会随仓库走。** 克隆或换机器后要重新执行
  上面第一条命令。
- 钩子文件 `pre-commit` 是一行 `#!/bin/sh` + 转调 `pre-commit.ps1`。
  这是因为 **Git for Windows 要求钩子可 spawn**，纯 PowerShell 钩子会报
  `cannot spawn ... No such file or directory`（第 142 轮踩过）。
